Bot details

Public channels can be joined automatically. Private channels need an invitation.

Used only to create the Slack app. Never saved by this tool on this Mac. Get a configuration token under Your App Configuration Tokens.

Review requested Slack permissions

Read mentions and conversations in channels the bot joins, reply in threads and DMs, read user details and reactions, and join the selected public channel. No admin scopes, file access, or shared slash command. The existing Paperclip user allowlist is inherited.

Slack authorization

Your new app:

  1. Install the app in your configured workspace and approve its permissions.
  2. Copy the Bot User OAuth Token from OAuth & Permissions.
  3. Open Basic Information. Under App-Level Tokens, generate a token with connections:write.

Both tokens must belong to this new app. Sent over SSH to encrypted Paperclip secrets on your existing VPS; not saved locally by this tool.

First invite the new bot to the private channel using Slack’s channel settings.

Deployment adds one bot connection to the existing plugin. All its Slack connections briefly reconnect. Paperclip itself is not restarted. Avoid editing plugin settings during deployment.
